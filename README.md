## En qué trabajamos

- **Microsoft Fabric** — arquitectura de plataforma de datos, dimensionamiento de capacidad
  (SKU), FinOps y migración desde Power BI Premium.
- **Power BI** — modelado tabular, optimización de performance y DAX, gobierno de reportes.
- **Capacitación** — programas oficiales y a medida (DP-600, DP-700, PL-300) para equipos de
  datos.
